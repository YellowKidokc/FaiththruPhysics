## SENTENCE HIGHLIGHTING SYSTEM

### Data Format
Each article embeds a JSON block generated by claim_jurisdiction.py:

```javascript
window.MDA_CLAIMS = [
  {
    id: "c-001",
    text: "High institutional density...",
    primary: "WHAT",    // WHAT | HOW | WHY
    what_pct: 65.2,
    how_pct: 20.1,
    why_pct: 14.7,
    confidence: 45.1,
    overreach: "none",  // none | low | medium | high
    pos_mismatch: false,
    paragraph_index: 3  // which <p> in the article body
  },
  // ...
];
```

### Behavior
1. User clicks "What" on the jurisdiction bar
2. All sentences classified as WHAT-primary get highlighted:
   - Background: rgba(24,95,165,0.12)
   - Left border: 3px solid #185FA5
   - Text color shifts slightly toward the jurisdiction color
3. If an entire paragraph is one type, wrap the whole paragraph in a
   U-shaped border (left + bottom + right, not top)
4. Clicking a highlighted sentence opens an explanation panel

### Explanation Panel
Opens BELOW the clicked sentence (not in a sidebar, not in a modal).
Contains:
- Jurisdiction label (WHAT/HOW/WHY) with color
- The claim text
- What kind of evidence this claim needs
- If overreach flagged: what the issue is
- If POS mismatch: what the grammar suggests instead

### Colors (locked)
- WHAT: #185FA5 (blue) — observations, evidence, data
- HOW:  #0F6E56 (green) — mechanism, structure, process
- WHY:  #854F0B (gold/amber) — interpretation, meaning, theology
- OVERREACH: #dc2626 (red) — jurisdiction crossing flag

## MATH TRANSLATION LAYER — INSIDE PROOF MODE

The MTL no longer uses inline callout boxes. Instead:

1. When user selects "Proof" tab, equations in the article get:
   - A subtle highlight/glow
   - An expand icon
2. Clicking an equation opens the three-layer presentation:
   - Layer 1: The equation itself (LaTeX/MathJax)
   - Layer 2: Plain English term-by-term translation
   - Layer 3: The isomorphism proof (physics ↔ theology side by side)
3. This panel opens below the equation, same as the claim explanation

### What gets deleted:
- `mtl-callout.css` — the gold-bordered inline boxes
- `mtl-callout.js` — the injection script
- All inline `<div class="mtl-callout">` blocks in articles

### What replaces them:
- `tp-domain-ribbon.js` — the unified component (this spec)
- Equation data embedded as `window.MDA_EQUATIONS` JSON

## LAYER SYSTEM ARCHITECTURE

The site has multiple "layers" that can overlay the article content.
Each layer activates through a different trigger but uses the same
rendering pattern: highlight on page → click to expand → panel below.

### Layer 1: Reading Level (Row 1 tabs)
- Simple: shortest version, no jargon
- Readable: standard article (default)
- Scholarly: academic citations, formal language
- Proof: activates equation overlays + claim audit

### Layer 2: Domain Composition (Row 2 bar)
- Click bar → expand detail panel showing scores per domain
- Already implemented as chi v5 dashboard contract
- Data: window.MDA_PAPER_PROFILE

### Layer 3: Claim Jurisdiction (Row 3 bar)
- Click What/How/Why → highlights sentences on page
- Click sentence → explanation panel
- Data: window.MDA_CLAIMS (from claim_jurisdiction.py)

### Layer 4: Math Translation (inside Proof mode)
- Equations glow when Proof tab active
- Click equation → three-layer expansion
- Data: window.MDA_EQUATIONS

### Layer 5: Citation/Source (future)
- Citation anchors in text → click to see source card
- Data: citations.db via Codex

### Layer 6: Theory Match (future — API)
- Claims matched to academic theories
- "This resembles Shannon's channel capacity theorem"
- Data: API call results cached in claims database
