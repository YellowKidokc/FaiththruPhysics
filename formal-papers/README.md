# Formal Papers

The ten formal papers are grouped into five thematic folders so they can be
browsed either as a full series or as bundled podcast-friendly arcs.

## Reader Map

If you want the simplest way to lead readers through the series, use this
five-part path:

1. `Foundations` - what reality is made of and where the framework starts.
2. `Truth and Force` - how signal, propagation, resistance, and distortion work.
3. `Measurement and Judgment` - how observation, entropy, and moral reckoning fit together.
4. `Redemption and Order` - how broken systems are restored and stabilized.
5. `Entropy and Coherence` - how collapse, opposition, and integration close the arc.

## Suggested Labels

If you want the folder names to read more like a guided library than an archive,
these are the strongest alternatives:

- `01_foundations/` -> `origin-and-substrate`
- `02_truth_and_force/` -> `signal-and-dynamics`
- `03_measurement_and_judgment/` -> `measurement-and-reckoning`
- `04_redemption_and_order/` -> `restoration-and-order`
- `05_entropy_and_coherence/` -> `closure-and-coherence`

I would keep the current numbered folder names on disk because they preserve
ordering and sort cleanly. Use the descriptive labels in the hub page and
navigation copy.
