# CD — Cross-Domain Coherence

Working copy of `[TX_A5.1] Cross-Domain Coherence Project`.

## Quick start

1. Copy good markdown from the desktop project into the matching `sources/` folder.
2. Upload those sources to a NotebookLM notebook for that domain.
3. Generate outputs in the order in [NOTEBOOKLM-WORKFLOW.md](./NOTEBOOKLM-WORKFLOW.md).
4. Rename audio in NotebookLM:
   - Debate → `D Title`
   - Deep Dive → `DD Title`
   - Critique → `AC Title`
5. Record final names in `notebooklm/manifest.json`.
