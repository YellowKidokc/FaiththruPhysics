## Naming System

Every package in this series uses:

1. **Series prefix:** `CD` = Cross Domain
2. **Package code:** 4-letter code (example: `CDCS` = Canonical Synthesis)
3. **Folder name:** `CD-{CODE}-{Domain-Name}`
4. **Display name:** `CD {Domain Name}`

## Studio Routine (Every CD Package)

1. Upload **3 sources** from `sources/`
2. **Slideshow** — type **Black it out** (no prefix)
3. **Deep Dive** — rename `DD Title`
4. **Critique** — rename `AC Title`
5. **Debate** — rename `D Title`
6. **Explainer video** — long form (no prefix)
7. **Vocabulary pass** → save `notebooklm/vocabulary.md`
8. **Download** into `notebooklm/`

| Output | Prefix |
|---|---|
| Deep Dive | `DD ` |
| Critique | `AC ` |
| Debate | `D ` |
| Slideshow | *(none)* |
| Explainer video | *(none)* |

## Slideshow Prompt — Black It Out

> Black it out. Minimal text per slide. One claim per slide. No paragraph blocks. High contrast. Let the spoken audio carry the explanation.
