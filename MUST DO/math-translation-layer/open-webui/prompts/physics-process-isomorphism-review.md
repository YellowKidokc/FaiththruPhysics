# Physics Process Isomorphism Review

Test whether a paper is actually architected one-for-one against a named physics process, rather than merely resembling one.

## Core question

What named physics process does the paper claim to mirror, and is that mapping truly one-for-one?

## Candidate process

Use **Wilsonian renormalization / effective field theory workflow** as the first candidate unless stronger evidence in the paper points elsewhere.

## Test questions

1. What is the named physics process this paper claims to mirror?
2. Is the mapping really one-for-one?
3. Which step pairings are strongest?
4. Which step pairings are weakest?
5. Does removing one step break the whole chain on both sides?
6. Is the order necessary, or just convenient?
7. Is this true process isomorphism or only structural resemblance?

## Working mapping to test

1. premises -> admissible assumptions / boundary conditions
2. reverse audit -> anomaly / breakdown detection
3. substrate -> field content / degrees of freedom
4. method -> transformation rule / coarse-graining procedure
5. equation -> effective dynamics / flow equation
6. verification -> consistency checks / invariance tests
7. demonstration -> hard-case application
8. convergence -> universality / fixed-point behavior
9. self-audit -> regime of validity / cutoff / known limits

## Output format

Return:

- claimed physics process
- step-by-step table
- strongest pairings
- weakest pairings
- dependency test
- order test
- final verdict:
  - process isomorphism
  - strong structural resemblance
  - weak analogy
  - not sustained
