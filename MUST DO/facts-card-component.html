Usage

How to Use This Component

Copy the CSS block and HTML structure into any article page. The accent color follows var(--highlight) automatically.

<!-- FACTS CARD — paste into any article --> <div class="facts-card"> <div class="facts-header"> <i class="fas fa-list-check"></i> FACTS — What This Article Establishes </div> <div class="facts-row"> <div class="facts-letter"> <span class="big">F</span> <span class="facts-word">Find</span> </div> <div class="facts-content"> <span>Your F content here.</span> </div> </div> <!-- Repeat for A, C, T, S --> </div>
Design rules:
1. Letter column is 80px wide (56px on mobile)
2. Each letter uses Oswald 3.5rem bold (2.5rem on mobile)
3. Glow is radial-gradient behind the letter, 12% opacity of accent
4. Word labels (Find/Anchor/Claim/Test/Source) sit at bottom of letter column
5. Hover scales letter 1.05× and lifts row background
6. Adapts to red or gold via single CSS variable swap
