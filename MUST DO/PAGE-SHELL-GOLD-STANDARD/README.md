# Page Shell Gold Standard

Documentation hub for the **faiththruphysics article page system** built on drv-00.

Start here: **[00_INDEX.md](00_INDEX.md)**

## Why this folder exists

The live site uses shared components under `faiththruphysics-site/components/` and markdown/audit data under `faiththruphysics-site-data`. This folder keeps the practical script workspace for the shared shell workflow:

1. See what each layer does (top bar, body, bottom bar, reading levels, math)
2. Run scripts and test report output from `scripts/`
3. Onboard agents via `skills/page-shell-builder.md`
4. Keep a durable note trail in local skills/docs/notes

**Rule:** Use `MUST DO/PAGE-SHELL-GOLD-STANDARD` as the active execution copy for shell tasks, then copy approved template or component deltas into `faiththruphysics-site/components/` and data outputs in `faiththruphysics-site-data`.
