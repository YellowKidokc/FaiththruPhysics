# Media Usage Policy (Draft)

## Current scope
- NotebookLM-generated audio/video/PDF/image assets
- Site ingestion into `faiththruphysics-site-data`
- Future website/landing page integration

## Working guidance
- Use only assets that have an explicit, traceable source (NotebookLM export or R2 copy).
- Prefer existing canonical naming already used in this project (prefix + title + extension).
- Keep "found locally / from R2 / missing / blocked" status in mapping notes.
- Do not republish assets if source rights are uncertain.

## Preliminary legal/compliance notes
- Google NotebookLM export docs show user ownership of generated content is retained in typical use, and exported media can be shared/downloaded.  
- Still required:
  - keep source attribution and provenance notes in mapping files,
  - avoid using any third-party source media embedded from notebooks without explicit permission,
  - check sensitive content/privacy constraints on linked references,
  - get legal review before publishing if there is any doubt.
