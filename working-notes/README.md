# Working Notes

This folder is for informal, one-off, or still-forming arguments.

Use it for pieces that are not part of the formal ten-paper series but still
need a clean place in the site tree.

## Folder Map

- `starting-point/` - opening ideas, raw claims, and first framing
- `truth-and-pushback/` - claims about truth, resistance, signal, and reply
- `measure-and-judgment/` - measurement, evaluation, and discernment
- `repair-and-order/` - restoration, fixing, and reassembly
- `breakdown-and-coherence/` - collapse, stability, and integration
- `one-offs/` - essays that do not fit a larger lane yet

Drop drafts into the relevant folder and keep the page title, filename, and
folder name aligned when possible.
