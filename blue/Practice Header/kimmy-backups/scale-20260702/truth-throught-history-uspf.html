The Shannon Isomorphism

The Universal Signal Persistence Framework is not a custom scoring system. It is a formal application of Claude Shannon's Channel Capacity Theorem (1948) to the problem of historical signal transmission.

C = B · log₂(1 + S/N)   [Shannon, 1948]
Strength = S · M · ln(1 + P)   [USPF]

The mapping is direct: signal integrity (S) times mechanism strength (M) corresponds to net signal power; survival pressure (P) corresponds to the signal-to-noise ratio; and the logarithmic term captures channel capacity under that noise load. This is not metaphor — it is the same mathematical structure, applied to a different channel domain.

The Three Variables

Why Multiplicative, Not Additive

The variables multiply rather than add. This is intentional: if any single dimension collapses to zero, the entire score collapses. A signal that lasted forever but lost all integrity scores zero. A signal that was perfectly preserved but never faced any pressure scores zero. Neither condition alone is sufficient. This prevents any single variable from compensating for complete failure in another.

The 10 Entropy Categories

Survival Pressure (P) is computed from ten distinct entropy mechanisms. Every historical destructive event maps into one or more of these categories. This prevents raw events ("King X outlawed it") from entering the equation directly — instead, their effect on transmission is encoded through standardized channels.

NOTE: Drift and semantic mutation are NOT included here. They belong entirely in S (Integrity) to prevent double-counting.

CategoryWeightDefinition
E1 — Physical Degradation0.75Material decay: erosion, corrosion, thermal stress, chemical breakdown

E3 — Deliberate Destruction1.00Intentional targeting: book burning, iconoclasm, systematic erasure
E4 — Carrier Suppression0.95Targeting transmitters: killing scribes, imprisoning teachers, banning practitioners
E5 — Transmission Capacity Collapse0.85Loss of ability to copy or propagate: literacy collapse, institutional breakdown, network failure
E6 — Encoding Loss0.70Loss during format change: oral→written, manuscript→print, analog→digital — always lossy
E7 — Structural Fragmentation0.70Signal breaks into disconnected parts: partial texts, broken structures, incomplete traditions
E8 — Context Loss0.80Supporting framework collapses: language extinction, symbolic system loss, cultural decoding failure
E9 — Access Restriction0.65Signal exists but is inaccessible: locked archives, restricted priesthoods, hidden knowledge systems
E10 — Centralization Risk0.85Single-point-of-failure structure: one manuscript, one monument, one institutional custodian

Total pressure load: L = Σ(wᵢ · Eᵢ) integrated over time. Events interact multiplicatively, not additively — a flood that destroys archives followed by a suppression regime that prevents reconstruction compounds, it does not simply add.

Anomaly Scoring

Raw strength scores are converted to Z-scores against a category-locked baseline — baselines are set from the existing registry before any new signal is entered. This prevents the comparison class from being tailored to favor a predetermined result.

METHODOLOGICAL HONESTY

This framework measures signal robustness — how well something survived transmission through a hostile channel. It does not directly measure truth. Persistence is not proof of correspondence with reality. The framework identifies structurally non-arbitrary signals that demand explanation. What that explanation is remains a separate inquiry. The anomaly score is the start of a question, not the end of one.

Pre-Registration Requirement

To be scientifically defensible, all variable definitions, baseline categories, and anomaly thresholds must be locked before the signal of interest is entered into the system. The registry enforces this by computing baselines from existing data prior to any new addition.

This framework is designed to be falsifiable. A challenge that holds up improves the system. A challenge that doesn't hold up strengthens the result.
