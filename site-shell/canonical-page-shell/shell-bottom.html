  • η(K) — receptivity of the system
  • λ·S(χ) — entropic loss, scales with state
Consciousness Ladder
dC/dt = O·G·(1−C) − S·C
  • O·G — openness times grace input
  • (1−C) — remaining capacity to receive
  • S·C — entropic loss, scales with state
