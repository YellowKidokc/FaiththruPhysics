The Architecture

This page demonstrates the shared top bar, domain pills, proof dropdown, reading level controls, and progress stripe using one reusable asset pair.

Why This Direction Wins

The good part of the attached note is not the one-off page. It is the architecture: one shared stylesheet, one shared JavaScript runtime, and one injector that attaches them to pages consistently.

  • Design changes happen in one place.
  • Pages stop drifting by folder and by series.
  • We can pilot on one series before touching the whole site.
