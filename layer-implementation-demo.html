layer implementation demo

One claim registry, three renderings.

Click a claim on the left. Then switch between the acclaim layer, the audit layer, and the math translation layer. The key idea is that the page does not hold three separate copies of the truth. It holds one claim object, and the layers render from that object.

Claims

How The Button Works

1. Select claim

The click sets the active `claimId` in state.

2. Choose layer

The layer button swaps the renderer: acclaim, audit, or math.

3. Render from registry

The UI reads the same claim object and maps it to the chosen layer.

4. Build output

The HTML is generated from the registry, so the copy stays aligned.

Implementation Rules

AcclaimWhat we want the reader to understand and feel.
AuditWhat holds, what is overstated, what is wrong, what needs evidence.
MathWhich symbol or formal structure each phrase maps to, and how exact that mapping is.
