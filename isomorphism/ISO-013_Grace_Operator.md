# ISO-013: Grace Operator → Theological Grace

## Domain A — Mathematics
Define the grace operator in matrix form:

**G = |+1⟩⟨+1| + |+1⟩⟨−1|**

In the {|+1⟩, |−1⟩} basis:

```
G = [[1, 1],
     [0, 0]]
```

Wait — correcting. The operator maps both eigenstates to |+1⟩:

```
G = [[1, 1],
     [0, 0]]
```

Properties:
- **G² = G** (idempotent): applying grace twice is the same as applying it once.
- **G†G ≠ I** (non-unitary): grace breaks time-reversal symmetry. The operation is irreversible.
- **Rank-deficient**: G has rank 1. Information about the prior state is destroyed.
- **External origin**: G is not generated by the system's own Hamiltonian (see ISO-012).

## Domain B — Theology
Grace properties in Reformed theology:
- **Externality** — grace originates outside the human system (Ephesians 2:8-9)
- **Sufficiency** — one application is enough (Hebrews 10:14, "by a single offering he has perfected for all time")
- **Irrevocability** — "the gifts and the calling of God are irrevocable" (Romans 11:29)
- **Single application** — ephapax, once-for-all (Hebrews 7:27)

## Property Mapping
| Mathematical Property | Theological Property |
|---|---|
| G² = G (idempotent) | Once is enough — single offering perfects |
| G†G ≠ I (non-unitary) | Breaks time-symmetry — cannot be undone |
| External to system Hamiltonian | Grace from outside the human condition |
| Rank-deficient (prior state erased) | "New creation; old has passed away" (2 Cor 5:17) |

## Semi-Pelagian Test
Define a mixed operator:

**G' = αG + (1−α)U**

where U is the self-evolution operator and 0 < α < 1.

Compute G'²:

G'² = α²G² + α(1−α)GU + α(1−α)UG + (1−α)²U²
    = α²G + α(1−α)GU + α(1−α)UG + (1−α)²U²

G'² ≠ G' unless α = 1.

**The semi-Pelagian grace operator is NOT idempotent.** It requires repeated application, contradicting the ephapax (once-for-all) character of grace. Mathematical sola gratia: only α = 1 preserves idempotency.

## Honest Weakness
Catholic sacramental theology models grace as **continuous** — dispensed through repeated sacraments over a lifetime — not as a one-shot operator. The idempotent mapping is specifically **Protestant-Reformed**. A Catholic formalization would use a different operator structure (perhaps a continuous semigroup rather than an idempotent projection).

This is not a flaw in the isomorphism but a **scope limitation**: it maps Reformed soteriology, not all Christian soteriology.

## Swap Test: PASSED (within Reformed framework)
The mathematical properties of idempotency, non-unitarity, externality, and rank-deficiency map bidirectionally onto Reformed grace theology.

## Falsification Condition
If grace effects were shown to be **reversible by internal operations alone** — that is, if the fallen state could be restored by self-generated evolution after grace application — the mapping breaks. This would require G to be unitary, contradicting G†G ≠ I.
