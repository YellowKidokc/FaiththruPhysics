# Isomorphism Registry

Structural isomorphism records documenting cross-domain mappings in the Theophysics framework.

## What This Is

Each ISO record documents a claimed structural correspondence between two domains. Every record includes the mapping, swap test, bidirectional predictions, falsification criteria, and honest classification.

## Discrimination Method

All records are evaluated against the **Four-Test Protocol** (HYP-ISO-001):
1. **Prediction Constraint** — Does the mapping constrain predictions in both domains?
2. **Symmetric Breaking** — Does breaking one domain break the other the same way?
3. **Connection Density** — How many independent correspondences exist? (7+ = statistically improbable as chance)
4. **Falsifiability Invitation** — Does the mapping state specific conditions that would destroy it?

1. Copy `ISOMORPHISM_TEMPLATE.md`
2. Name: `ISO-[NNN]_[Short_Description].md`
3. Fill every field. Run all tests honestly.
4. Update this README's registry table.
5. Add the record to `Isomorphism_Registry.html`.

## Rules

- An isomorphism that can't be falsified isn't an isomorphism — it's a belief.
- "Analogy Only" is not a failure. It's an honest classification.
- The swap test is mandatory. If roles are interchangeable, the mapping is arbitrary.
- "OBSERVATION CONFIRMED, MECHANISM UNSOLVED" is a valid status. Observation precedes explanation.
