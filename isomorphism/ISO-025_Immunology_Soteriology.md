# ISO-025: Immunology ↔ Soteriology — The Immune System of the Soul

## DOMAINS

**Domain A — Immunology**
The immune system performs binary classification: self vs. non-self. Two failure modes define the pathology space: autoimmunity (attacking self — false positive) and immunodeficiency (failing to attack non-self — false negative). The ROC curve (Receiver Operating Characteristic) quantifies the tradeoff between sensitivity and specificity. A healthy immune system optimizes both simultaneously.

**Domain B — Theology (Sanctification)**
Sanctification performs binary classification: holy vs. unholy. Two failure modes define the theological pathology space: legalism (condemning the permissible — false positive) and antinomianism (permitting the condemned — false negative). A mature believer optimizes discernment — high sensitivity to genuine sin, high specificity to genuine holiness.

## TESTS

**Swap Test**: PASSED. Substituting immune terminology into theological discourse generates non-trivial predictions:
- "A church with no boundary defense will suffer infection" → meaningful ecclesiological claim.
- "Legalism is autoimmunity of the soul" → generates the prediction that legalistic communities will exhibit self-destructive pathology (burnout, shame spirals, splits) — which is empirically observed.
- "Vaccination = controlled temptation exposure" → predicts that sheltered communities produce immunologically naive believers — which matches observed patterns of deconversion after first encounter with doubt.

**Bidirectional Prediction**:
- Forward (immunology → theology): Immune privilege predicts the existence of sacred spaces with suspended normal rules. This is independently attested in Scripture (Holy of Holies access restrictions).
- Reverse (theology → immunology): The theological insistence on "one body, many members" predicts that immune function depends on systemic integration — no single cell type is sufficient. This is immunologically correct.

**Falsification**: If immune dysfunction patterns do not map to theological dysfunction patterns. Specifically: if autoimmune-like dynamics (self-attack) are not observed in legalistic communities, or if immunodeficiency-like dynamics (failure to exclude) are not observed in antinomian communities.

## CLASSIFICATION

**Rating**: Testing / High confidence.

**Strength**: The dual-pathology structure (two failure modes defining a 2D error space) is a nontrivial structural parallel. It is not a vague metaphor — it is a precise mapping between classification error types. The ROC curve framework provides quantitative structure: sanctification can be modeled as movement toward the upper-left corner (high sensitivity, high specificity).

**Novel insight**: The cytokine storm ↔ corporate sin correspondence is particularly strong. A cytokine storm is not caused by the pathogen but by the immune system's own overreaction — just as church splits are often caused not by the original sin but by the community's disproportionate response.
