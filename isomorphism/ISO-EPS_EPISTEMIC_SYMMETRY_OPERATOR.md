## 2. The Extension: Split Alpha

For any document D, position P, argument A, or worldview W:

    α_self(D) ∈ [0,1]  = strictness of standard applied to D's own claims
    α_other(D) ∈ [0,1] = strictness of standard applied to competing claims

    0 = maximum mercy  (no evidence required, no consequences admitted)
    1 = maximum justice (full evidence required, full consequences accepted)

The Epistemic Symmetry Metric:

    Δα(D) = |α_self(D) − α_other(D)|  ∈ [0,1]

Interpretation:

    Δα = 0    →  symmetric standards       (Cross configuration)
    Δα > 0    →  asymmetric standards       (ideological drift)
    Δα → 1    →  maximum asymmetry          (ideology signature)

## 3. The Cross as Symmetry Point

The Cross is not "mercy wins over justice." The Cross is the configuration

absorbed by the Judge.

    Standard:  The law applies equally. The Judge does not exempt himself.
    Payment:   The Judge pays the penalty for all.
    Structure: Symmetric standard, asymmetric payment.

This is the distinction between the standard (which must be symmetric)
and the cost (which is borne voluntarily by the one with the capacity
to bear it). Justice is in the standard. Mercy is in the payment.

## 4. Domain Classification (Pre-Condition)

Δα is ONLY valid within a single domain. Cross-domain comparison requires
domain translation first.

### Type 1: Truth-Apt Domains

    Mathematics       — Standard: proof, derivation
    Empirical science — Standard: falsifiability, reproducibility
    Biblical claims   — Standard: textual exegesis, historical context
    Historical facts  — Standard: documentary evidence, scholarly consensus
    Formal logic      — Standard: validity, soundness

In these domains: Δα > 0 means the position is structurally dishonest.
The argument may still reach a correct conclusion, but the reasoning
that got there is asymmetric.

### Type 2: Pluralism-Apt Domains

Multiple legitimate positions exist within bounds. Asymmetry is dishonest
argumentation, but the content itself is not judged.

    Political philosophy  — Bounds: constitutional, democratic norms
    Economic policy       — Bounds: market/system constraints
    Prudential judgment   — Bounds: moral constraints
    Governance structure  — Bounds: rule-of-law constraints

In these domains: Δα > 0 means the ARGUMENT is structurally dishonest.
The POSITION (Democrat, Republican, libertarian) is not scored.
A 50/50 split with Δα = 0 on both sides is legitimate disagreement.

### Type 3: Worldview Lenses

Frameworks for interpretation, not claims. They filter evidence; they do
not make evidentiary claims directly.

    "Government should be small"     — Political philosophy lens
    "Markets self-correct"           — Economic framework lens
    "Scripture is inerrant"          — Theological framework lens
    "Systemic oppression exists"     — Sociological framework lens

Lenses are not scored by Δα directly. However, ARGUMENTS MADE THROUGH
the lens are scored. The lens is infrastructure; the claim is testable.

### Domain Classification Rule

    Δα(D, domain) = |α_self(D, domain) − α_other(D, domain)|

    Valid:   Both claims evaluated within the same domain
    Invalid: Cross-domain comparison without translation

    Example (VALID):
      Physics demands math proof from MY theory but accepts anecdotes
      from THEIR theory → Δα > 0 (same domain, asymmetric standard)

    Example (INVALID):
      Physics demands math proof; theology demands textual consistency
      → Different domains, different tools. NOT asymmetry.

    Example (VALID):
      Theology demands exegesis from MY interpretation but "you're
      reading too much into it" from THEIR interpretation → Δα > 0

## 7. Limitations and Kill Conditions


### 7.1 Symmetry Is Necessary, Not Sufficient

    Δα = 0 does not guarantee truth.
    A cult could apply equally deranged standards to everyone.
    Symmetry detects structural honesty, not correctness.

    Δα is a FILTER, not a VERDICT.
    It eliminates ideology. It does not confirm truth.
    Truth requires Δα = 0 AND correct standards.

### 7.2 Rhetorical vs Ontological

    Δα measures documentary/argumentative posture, not reality.
    A true position CAN be argued asymmetrically (Δα > 0).
    A false position CAN be argued symmetrically (Δα = 0).

    The operator catches HOW you argue, not WHAT you argue.

### 7.3 Temporal Staging

    A new hypothesis gets provisional status during testing.
    This is NOT asymmetry IF the advocate would grant the same
    provisional status to a competitor's new hypothesis.
    True asymmetry is about the PRINCIPLE, not the PHASE.

### 7.4 Domain Crossing

    Δα is invalid across domains without translation.
    Demanding mathematical proof from theology while accepting
    intuitive arguments in physics is a domain error, not
    an asymmetry measurement.

### Kill Conditions

    KC-1: Find a position that is structurally honest (by all other
          measures) but registers Δα > 0. The operator produces
          false positives.

    KC-2: Find a position that is structurally dishonest (by all
          other measures) but registers Δα = 0. The operator produces
          false negatives.

    KC-3: Show that the Cross configuration does NOT require Δα = 0
          in standard application. The theological grounding fails.

    KC-4: Show that Kant, Popper, equal protection, and Shannon
          do NOT converge on symmetric standard application. The
          convergence claim fails.
