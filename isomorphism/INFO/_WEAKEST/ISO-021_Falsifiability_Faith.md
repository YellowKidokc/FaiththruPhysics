# ISO-021: Falsifiability ↔ Faith Seeking Understanding

## DOMAINS

**Domain A — Philosophy of Science (Popper)**
Popperian epistemology: knowledge advances through conjecture and refutation. A hypothesis is proposed, tested against observation, and revised or discarded. The loop is: Conjecture → Prediction → Test → Refute/Corroborate → Revise. The key virtue is willingness to be wrong.

**Domain B — Theology (Anselm)**
Fides quaerens intellectum: faith seeking understanding. Belief is not the endpoint but the starting posture from which inquiry proceeds. The loop is: Trust → Act → Encounter → Refine understanding → Deepen trust. The key virtue is faithfulness under uncertainty.

## THE MAPPING

| Scientific Concept | Theological Concept |
|---|---|
| Hypothesis | Creedal commitment |
| Empirical test | Lived obedience / prayer |
| Falsification | Suffering / unanswered prayer |
| Theory revision | Theological maturation |
| Corroboration | Experiential confirmation |
| Willingness to be wrong | Humility before God |

## TESTS

**Swap Test**: WEAK. Swapping terms produces statements that are technically coherent but trivially so. "Faith is a hypothesis about God" and "a hypothesis is faith in a theory" are both sayable but neither generates novel insight. The mapping works for any rational activity with an iterative structure — learning a language, debugging code, improving a recipe.

**Bidirectional Prediction**: Limited. The scientific loop does not predict anything specific about theology, nor does the theological loop predict anything specific about science. Both predict "iterative refinement," which is too generic to be informative.

**Falsification**: N/A. The mapping is too generic to falsify meaningfully. Any rational, iterative process would satisfy the same structural correspondence.

## CLASSIFICATION

**Rating**: Candidate / Low confidence / Analogy only.

**Triviality concern**: SIGNIFICANT. This is the central problem. The hypothesis-test-revise loop maps onto virtually any disciplined inquiry: martial arts training, psychotherapy, engineering design, cooking. The mapping to theology is real but not special. It does not demonstrate a deep structural correspondence between science and faith — it demonstrates that both are instances of rational activity, which is unsurprising.

**What it does establish**: That faith (in the Anselmian sense) is not the opposite of rational inquiry but a species of it. This is apologetically useful but isomorphically thin.
